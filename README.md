## Diploma thesis

*Bitemporal Correctness and State Recovery in Memory-Based Temporal Graph Networks* · In progress

My thesis studies how delayed and out-of-order interactions affect the state of
memory-based Temporal Graph Networks. I distinguish when an event occurred from
when the model could observe it. Using chronological replay as a reference, I
examine local memory repair, selective dependency replay, and full recomputation.
The evaluation focuses on state fidelity, recovery latency, and computational
cost under controlled delays and graph workloads.

## Financial Systems and Quantitative Research

- **Trading 212 Portfolio Intelligence.** Completed local implementation and
  synthetic-data demo for read-only portfolio analysis. It combines
  reconciliation and exact decimal accounting with asynchronous jobs and
  web, API, and MCP interfaces. Production qualification is outside the demo
  scope. [Portfolio Intelligence](https://github.com/ntua-el21026/trading212-portfolio-intelligence)
- **AI-Assisted Quantitative Trading Research.** An offline framework for causal
  evaluation and deterministic financial simulation. It models execution and
  risk controls, checks accounting against independent fixtures, and records
  reproducible configurations and results. Historical profitability remains
  unverified. [Research framework](https://github.com/ntua-el21026/ai-assisted-quant-research)
- **Polymarket Pair Maker.** Market-microstructure research on conservative
  YES/NO quoting and inventory risk. The deterministic paper simulator models
  queues, fills, collateral, and inventory. Live order placement is outside
  its scope, and real-market profitability remains unverified.
  [Paper simulator](https://github.com/ntua-el21026/polymarket-pair-maker)
